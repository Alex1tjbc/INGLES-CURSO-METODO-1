# Aplicación CANCHA-48 PRO

Aplicación web progresiva e independiente para el ciclo auditivo de 48 misiones.

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

La carpeta `dist/` contiene la edición estática instalable. La rama `gh-pages` conserva la versión publicada.

## Privacidad

El diagnóstico, avance y grabaciones permanecen en el dispositivo. La aplicación no utiliza una cuenta de ChatGPT ni envía el progreso a un servidor.
